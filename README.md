## 用支付宝开 Pro 的两条路

**路线一：自己折腾礼品卡**

典型流程是支付宝 → 苹果礼品卡 → 美区 Apple ID → App 内购。支付宝里搜「苹果礼品卡」或走 Pockyt Shop 都能用人民币买到美区卡密，2026 年 7 月的一次实测记录里，$20 美区礼品卡实付约 ¥135.98（账单州选 Oregon，无额外销售税）。

这条路真实存在，但坑也不少：

- Pro 不是直接能买的。iOS 端通常要先开 Plus，App 内才会出现升级 Pro 的入口，苹果会先按 Pro 全额扣款，过几天再退掉 Plus 那部分差额。
- 礼品卡偶发兑换失败。有用户反馈连续换三张卡都提示「此代码无法使用」，最后换了一个全新美区 ID 才成功，推测和账号历史消费记录有关。
- 全流程需要代理、海外 Apple ID、免税州地址，任何一环出问题都要重来。

这条路的逻辑很直接：你把支付宝付给平台，平台在官方订阅入口上，把 Plus 或 Pro 开到你自己已有的 ChatGPT 账号里。搜「ChatGPT Pro 支付宝」时反复出现的 BeWild.ai（也叫 WildAI）就是走的这个模式。

很多人以为 Pro 只有一档，其实 OpenAI 目前是两档，这也是国内第三方平台最常被搞混的地方。

几个容易误解的点：

- 5x 和 20x 描述的是**用量**，不是模型智商的倍数。两档的 Pro 核心能力相同，包括 Pro 模型、Codex、Deep Research、图片生成、文件上传这些。

- OpenAI 目前不为个人 Plus / Pro 提供年付或一次预付多月。看到「一次买一年」的说法，值得多问一句。

怎么选其实不用纠结太久：先记录一周，看你触发了几次额度提示、每次等多久、有多少任务被迫换到低档模型。如果这些等待没有明显影响你的交付，那 20x 每月多出的 100 美元大概率是过度购买。

## 什么情况该走官方，什么情况适合用支付宝
